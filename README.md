# QR-FIT-ACADEMIA

Aplicativo PWA de orientação para aparelhos de academia por QR Code.

## Etapa 1: Leg Press 45°

**Em desenvolvimento. O aplicativo completo ainda não está publicado.**

A base original `app-academia-2.html` inclui seis variações do Leg Press. Três ZIPs de vídeos foram recebidos, mas ainda precisam ser inspecionados para identificar os MP4 correspondentes e evitar mostrar demonstrações incorretas.

### Próximas entregas
1. Preservar a versão original do HTML.
2. Substituir exatamente as seis demonstrações pelos MP4 corretos.
3. Melhorar instruções, acessibilidade, apresentação de calorias e reprodução.
4. Integrar manifesto, service worker, ícones e download offline verificável.
5. Gerar QR Code definitivo após publicação HTTPS.
6. Testar a instalação e os vídeos offline no Android.

### Estado técnico
`manifest.webmanifest` e `service-worker.js` foram adicionados como **base técnica**. Sozinhos, eles não instalam nem disponibilizam os vídeos offline; dependem da integração ao aplicativo e de testes de publicação.
